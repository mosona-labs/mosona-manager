Mosona Manager 是一款面向团队 / 个人的项目管理、服务器监控和终端管理工具，具备完善的项目权限控制和基于 SSH 的远程管理协议。

> 无被控程序依赖：无需在被管理服务器上安装任何被控程序，简化部署并降低运维成本。

## 功能特色
- **项目管理**：轻松创建和管理多个项目。
- **用户权限**：为每个项目分配和控制用户权限。
- **SSH 远程管理**：通过 SSH 安全地管理服务器和终端。
- **实时监控**：实时监控服务器性能和项目状态。
- **通知提醒**：接收重要事件的警报和通知。
- **网页界面**：用户友好的网页界面，便于导航和管理。
- **API 接口**：RESTful API，方便与其他工具和服务集成。
- **日志与审计**：完整记录系统内的所有操作和变更。
